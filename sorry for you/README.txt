SORRY FOR YOU — GitHub Pages version (static website)

This version is prepared for GitHub Pages. It does NOT need Python, Flask, ngrok, or a running laptop once published.

FILES
- index.html: website homepage
- assets/css/style.css: styles
- assets/js/script.js: interactions
- assets/photos/: your 3 photos
- assets/music/lagu.mp3: audio file

PUBLISH ON GITHUB PAGES
1. Sign in at https://github.com
2. Create a new repository (for example: sorryforyou). For the easiest setup, choose Public.
3. Upload the CONTENTS of this ZIP (index.html and assets folder) to the repository root, not the ZIP file itself.
4. Open repository Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait a few minutes. GitHub will show the public website link in Settings -> Pages.

PRIVACY NOTE
If you use a public repository, the photos and music files you upload may be publicly accessible. Only publish photos you have permission to share. If you want the repository private, check the current GitHub Pages plan and repository eligibility first.

The audio file is included from the uploaded project. Make sure you have permission to publish/share it online.
